# 로컬 웹앱 사용법

저장된 시세와 모의 주문 장부를 브라우저에서 보고, 기존 위험 계산기로 진입 가정을 검토한다.
[Issue #41](https://github.com/krdn/gon-stock02/issues/41) · [구현 기록](../tasks/41-webapp.md)

프로젝트 루트에서 실행한다.

```sh
uv sync --locked
uv run gs02-web
```

주소는 <http://127.0.0.1:8787>이다. 실행 터미널에서 `Ctrl-C`로 종료한다.
다른 작업 폴더에서는 `--root /path/to/gon-stock02`, 포트가 사용 중이면 `--port 8789`를 지정한다.
웹 UI는 Python 패키지에 포함되어 별도 Node 설치·프런트엔드 빌드가 필요 없다.

| 화면 | 사용 방법과 의미 |
| --- | --- |
| 대시보드 | 4종목 중 선택, 일봉/1분봉·수집 묶음·최근 60/120개/전체 변경. 날짜를 입력하고 기간 적용. 관측 표는 최신순 20행씩 이동하며 CSV는 적용된 전체 날짜 구간을 내려받는다. |
| 데이터 탐색 | 수집 묶음별 건수·관측 범위·결측 후보·공식 모의 지원 여부·파일 해시 대조를 본다. 일봉과 과거 분봉의 지원 상태를 구분한다. |
| 위험 계산 | 진입가·손절가·왕복 주당 비용을 입력한다. 운용 상태의 초깃값은 정책의 가상금이며 실제 잔고가 아니다. 보유·대기 노출과 예약 손실도 수정할 수 있다. |
| 모의 주문 장부 | 저장된 최근 200개 주문의 상태·주문/체결/잔량을 조회한다. 미연결·빈 장부·조회 실패를 구분한다. |

차트의 가로축은 실제로 저장된 관측 순서다. 누락 구간을 생성하거나 보간하지 않는다.
120개까지는 OHLC 캔들, 그보다 많으면 모든 관측 종가를 선으로 표시하며 아래에는 거래량을 표시한다.
0가격 기록은 표·CSV에 보존하되 시세 요약과 차트 가격 계산에서 제외한다. 마지막 관측이 0가격이면 가격 확인 필요로 표시한다.
등락은 선택한 구간의 마지막 두 유효 관측 종가 사이 변화이며, 마지막 두 기록 중 0가격이 있으면 비교하지 않는다. 시각은 KST이며 원주가 자료다.
반복 수신 자료는 같은 봉의 가장 나중 응답을 표시하되 관측 횟수를 보존한다. 여러 응답의 거래량을 합산하지 않는다.
CSV도 화면에서 선택한 최신 관측 버전이며 원시 반복 응답 전체의 내보내기는 아니다.

수집 자료는 기본적으로 `.local/history-*/manifest.json`과 `.local/minute-capture-*/manifest.json`에서 찾는다.
별도 자료 루트는 `--data-root /절대/경로`로 지정한다. 그 아래 동일한 이름 규칙의 묶음을 읽는다.
`pages.jsonl`과 `bars.jsonl` 또는 `observations.jsonl`의 SHA-256이 manifest와 일치해야 차트·CSV를 제공한다.
원본 파일을 수정하지 않으며 한 파일 64MiB, 한 묶음 정규화 자료 100,000행을 넘으면 조회를 거절한다.
손상·부분 수집·자료 없음은 그대로 표시하며 예시 시세로 대체하지 않는다.

장부는 `~/.local/state/gon-stock02/*/orders.sqlite3`에 정확히 하나 있을 때 자동 연결한다.
여러 개면 `--ledger /사용할/장부/orders.sqlite3`를 명시한다. 경로는 서버 실행자가 지정하며 웹 입력으로 받지 않는다.
SQLite `mode=ro`와 조회 전용 트랜잭션을 사용하므로 `SUBMITTING`을 `UNKNOWN`으로 바꾸는 복구도 실행하지 않는다.
계좌번호·계좌 디렉터리·주문 의도 ID·브로커 주문 ID·자격증명은 API에 포함하지 않는다.

서버는 `127.0.0.1`에만 바인딩한다. 원격 클라이언트와 외부 Host를 거절하며 데이터 API는 같은 Origin에서만 호출한다. 다른 페이지의 링크로 HTML 첫 화면을 여는 것은 허용한다. 외부 CDN은 사용하지 않는다.
단일 사용자 로컬 실행 범위이며 외부 호스팅·원격 로그인·자동 시작 서비스는 구성하지 않았다.
새로고침은 로컬 파일을 다시 읽는다. 브로커 인증·조회·수집·주문·취소·백테스트를 실행하는 API가 없다.

위험 계산은 새 시세와 거래 가능한 시장을 **가정**한다. 비용은 필수 입력이고 실제 계좌 요율을 추정하지 않는다.
계산이 통과해도 주문은 활성화되지 않는다. 정책 파일에 주문 ON이 기록되어 있어도 웹 계산 결과의 `allowed`는 항상 false다.
실제 데이터·계좌 비용 검증은 [#37](https://github.com/krdn/gon-stock02/issues/37), [#38](https://github.com/krdn/gon-stock02/issues/38)에서 계속한다.

검사는 기존 명령을 사용한다.

```sh
uv run python -m unittest discover -s tests -v
uv build
```
