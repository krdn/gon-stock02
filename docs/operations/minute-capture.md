# 모의 당일 분봉 수신 기록

같은 분봉의 값이 갱신되는 과정을 실제 수신 시각과 함께 보존한다. [Issue #11](https://github.com/krdn/gon-stock02/issues/11) · [지원·사용 조건](../research/data-contract-2026-11.md). 주문은 전송하지 않는다.

## 실행과 중단

공식 날짜별 개장·정지 상황을 확인한 뒤 KRX 모의환경에서 실행한다.

```sh
uv run gs02 capture --seconds 60 \
  --output ".local/minute-capture-$(date +%Y%m%dT%H%M%S)"
```

`--seconds`는 1~120초의 관측 반복 기한이다. 진행 중인 인증·요청·호출 간격 대기로 종료가 더 늦을 수 있다. 네 종목을 차례로 조회하고 다음 순회까지 최대 5초를 기다린다. 모든 REST 요청은 기존 계좌별 호출 간격 제어를 거친다. 시장은 KRX로 고정하며 `--venue NXT`는 인증 전에 거절한다.

1~3초처럼 짧은 기한은 일부 종목만 기록하고 `incomplete`와 종료코드 1로 끝날 수 있다. 네 종목 관측에는 예시의 60초를 사용한다.

현재 시각을 조회 상한으로 사용한다. 기존 과거 수집기의 15:30 고정 창을 적용하지 않는다. 이것이 특별개장일의 시간을 확인했다는 뜻은 아니다.

호출 제한·인증/통신 실패·빈 응답·잘못된 봉·날짜 변경에서 재시도 없이 중단한다. 출력 경로는 새 디렉터리여야 한다. 재개할 때도 새 경로로 실행한다. `Ctrl-C`로 중단한 묶음의 `running` 상태나 손상된 manifest는 미완료로 취급한다. 이 명령은 예약 실행이나 상시 수집기를 설치하지 않는다.

## 기록과 판정

| 파일 | 내용 |
|---|---|
| `pages.jsonl` | 요청 입력·호출 결정/수신 시각·시세 필드만 남긴 원본·응답 순번 |
| `observations.jsonl` | 정규화 봉과 해당 응답의 순번·수신/가용 시각·미확정 표시 |
| `manifest.json` | 시작 시 소스 파일 해시·건수·오류·종료 상태·두 자료 파일 해시 |

같은 종목·봉 시각이 반복되어도 행을 덮어쓰거나 제거하지 않는다. 예를 들어 같은 봉의 거래량이 5에서 7로 바뀌면 두 버전을 각각의 수신 시각으로 보존한다. `available_at=received_at`은 그 응답 버전을 관측한 시각이다. 공급자가 해당 봉을 처음 게시한 시각이나 과거 거래 당시 수신 시각이 아니다. 종목별 조회 시각도 서로 다르다.

`requested_at`은 인증·호출 슬롯 대기 전의 호출 결정 시각이다. 실제 전송 시각을 측정하지 않았으므로 `received_at-requested_at`을 순수 네트워크 지연으로 해석하지 않는다. 대기 중 분 경계를 넘고 입력 상한보다 늦은 봉을 받으면 검증 오류로 중단할 수 있다. 실제 응답 양상은 장중에 확인해야 한다.

`collection_complete=true`와 종료코드 0은 네 종목 모두에서 유효한 관측 행을 한 번 이상 저장했다는 뜻이다. 거래일 전체의 완전성·봉 확정·정보의 실시간성을 증명하지 않는다. 요청 건수는 클라이언트 조회 호출 횟수이며 인증 POST를 포함한 패킷 개수가 아니다.

모든 행은 `finality=unverified`, `strategy_eligible=false`다. 전체 묶음도 세션·과거 정지·완전성·봉 확정·백테스트 준비를 미검증으로 남긴다. 무거래 봉을 생성하거나 결측을 보간하지 않는다. 현재가의 거래정지 표시나 WS 정지 플래그는 해당 관측 시점의 정보이며 과거 정지 이력을 대신하지 않는다.

## 확인한 범위

2026-11-14에는 시계·HTTP 응답을 대체한 자동 검사만 실행했다. 최신 배열 갱신 특례는 [공식 규격](https://apiportal.koreainvestment.com/files/download/apiCollection/API_COLLECTION)에서 확인했으나 확정 판정 규칙은 미해결이다. [검증 증거](../evidence/minute-capture-2026-11-14.json)에 검사·원본 해시·미실행 범위를 구분했다.

장중 실제 수신은 미실행이다. 날짜별 공식 세션·정지, 기업행동 공시, 비용·호가 대조와 보수적 체결 모형은 Issue #11에 남는다. 이 기록만으로 주문이나 백테스트에 연결하지 않는다.
