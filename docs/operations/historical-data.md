# KRX 과거 시세 수집과 품질 점검

“과거 데이터 수집·품질 확인” 작업은 모의환경 시세를 수집하고 검증 가능한 파일로 보존한다. [Issue #9](https://github.com/krdn/gon-stock02/issues/9) · [검증 설계](../research/validation-design-2026-11.md).

## 실행

```sh
uv sync --locked
uv run gs02 history --start 2025-11-14 --end 2026-11-13 \
  --minute-start 2026-11-09 --output .local/history-20261113
```

`--start`와 `--end`는 일봉 범위다. `--minute-start`부터 `--end`까지 평일의 1분봉을 조회한다. 세 날짜는 필수이며 전체 범위는 최대 365일 간격이다. 네 종목과 KRX를 고정하고 기존 모의 인증 저장소를 사용한다. 인증 외 요청은 시세 GET이며 주문을 전송하지 않는다.

출력 디렉터리는 새 경로여야 한다. 기존 파일은 덮어쓰지 않는다. 중단·실패 후에도 원본 디렉터리를 보존하고 새 경로로 실행한다. 자동 재시도는 없다. 브로커 호출 제한을 받으면 즉시 추가 요청을 중지한다. 새 프로세스 인증에도 별도 제한이 있으므로 연속 재실행을 피한다.

| 파일 | 내용 |
|---|---|
| `pages.jsonl` | 시세 필드만 남긴 응답, 요청 입력·TR·수신 시각. 인증값·헤더·응답의 계좌 관련 영역은 제외 |
| `bars.jsonl` | 종목·주기·시각순 정규화 OHLC·거래량·거래대금 |
| `manifest.json` | 범위·페이지·건수·가용 시각·결측 후보·실패 사유와 두 자료 파일의 SHA-256 |

종료코드 0은 모든 종목·주기의 수집 루프와 구조 검사를 통과했다는 뜻이다. 일부 실패도 manifest에 기록하고 종료코드 1을 반환한다. 프로세스 강제 종료로 manifest가 없으면 미완료 자료다. 실패 이전에 모은 행을 완전한 자료로 사용하지 않는다.

## 검사와 해석

일봉은 원주가(`FID_ORG_ADJ_PRC=1`)로 요청한다. 일봉은 마지막 날짜의 전날, 분봉은 마지막 시각의 이전 분 정각부터 다음 페이지를 조회한다. 실제 모의 응답에서 `13:20:59` 요청이 `13:21` 봉을 다시 포함했으므로 초 단위 커서를 쓰지 않는다.

중복·페이지 역전·미래 시각·잘못된 날짜·OHLC 관계·음수·비정수 수량을 검출한다. 범위 이전 응답은 원본에 남기고 `outside_window_rows`로 센다. 0가격·0거래량은 임의의 정상 가격으로 바꾸지 않고 별도 표시한다. 0가격 행이 있으면 구조 검사 통과를 표시하지 않는다.

분봉의 `acml_tr_pbmn`은 `cumulative_turnover`로 보존한다. 분별 거래대금으로 이름을 바꾸거나 종가×거래량으로 대체하지 않는다. 예를 들어 누적값 5,000원은 해당 1분의 거래대금 5,000원을 뜻하지 않는다.

결측 후보는 평일 09:00~15:19의 분 시각과 비교한다. 15:20~15:29 종가 단일가 구간을 일반 연속매매 분봉으로 요구하지 않는다. 15:30 응답은 보존한다. 특별개장·휴일·무거래·정지·봉 시각 정의를 공식 달력과 대조하지 않았으므로 결측 후보를 수집 장애로 단정하지 않는다. 누락 봉을 0거래량으로 생성하지 않는다.

일봉은 종목 사이의 관측 날짜 차이와 미관측 평일을 기록한다. 네 종목에 공통으로 빠진 날짜도 휴일로 확정하지 않는다. 현재 날짜의 일봉 확정 여부와 기업행동·자료 이용 조건도 별도 검증이 필요하다.

## 다음 단계의 조건

`backtest_ready=false`는 계속 유지한다. 당시 수신 시각·기업행동·과거 세션/정지·호가·비용이 아직 없다. 수집 시각을 과거의 정보 가용 시각으로 소급하지 않는다. 이번 수집은 KRX 요청 자료이며 NXT·통합시장이나 장중 체결 가능성의 증거가 아니다.

백테스트에 연결하기 전에 결측 후보와 봉 시각 정의를 확인하고, 기업행동·비용 계약과 보수적 체결 가정을 고정해야 한다. 실측 데이터 범위·실패·검증 결과는 [수집 증거](../evidence/historical-data-2026-11-13.json)에 남긴다.
