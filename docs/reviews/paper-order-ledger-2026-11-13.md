# 모의 주문 장부 검토 상태

독립 코드 리뷰는 **미실행**이다. 구현 완료나 테스트 통과와 구분한다. 이 상태에서는 PR을 리뷰 대기로 남긴다.

- 요청 설정: `~/.codex/bin/review-llm --dry-run`에서 `claude-opus-5-5`, `high` 확인.
- 실행: 요구사항·코드·테스트·계약 문서 11개를 stdin으로 전달했다. 비밀값과 계좌 원문은 제외했다.
- 결과: 종료코드 1, `is_error=true`, `modelUsage={}`. 실제 반환 모델·리뷰 본문 없음.
- 응답: `You've hit your 5-hour limit · resets 11:30pm (Asia/Seoul)`.
- 자동 모델 대체·effort 변경은 하지 않았다. 2026-11-13 23:30 KST 이후 동일 설정으로 실제 리뷰를 받아야 한다.
- 22:00 KST 재개: 로컬·PR #6 head `df661d9549caa0ffb69fd93839ad038b73b8b0bb` 일치, 원격 Python/configuration CI 성공을 확인했다. 동일 설정으로 변경분·관련 자료 11개를 다시 전달했으나 종료코드 1, `is_error=true`, `modelUsage={}`와 같은 한도 안내를 받았다. 리뷰 미실행 상태를 유지하며 코드 변경·주문 전송·병합은 하지 않았다.

직접 점검에서 응답 대소문자 충돌, 다른 계좌 DB 복사, 연속조회 종료 표시 누락, 취소행의 잘못된 원주문 연결을 재현하고 수정했다. 최종 전체 테스트 60개·wheel/sdist 빌드 통과. 두 개의 별도 프로세스로 계좌 잠금과 호출 간격을 검증했다. 배포 아카이브에서 로컬 상태·인증 파일 제외, 상대 문서 링크 20개 확인.

실제 모의계좌의 빈 주문·잔고 대조와 재시작 조회는 성공했다. 마지막 수정 후 조회도 일치했다. [증거](../evidence/paper-order-ledger-2026-11-13.json). 실제 모의 접수·체결·취소는 미검증이고 주문은 0건이다.

문서 STE 검사는 `docs/conventions/ste100-writing.md` 부재로 실행 실패했다. 문서 검사 통과로 표시하지 않는다. 다음 단계는 독립 리뷰·필요한 수정 검증·PR/main CI·원격 검증이며, 장중 계약 실증은 별도다.
