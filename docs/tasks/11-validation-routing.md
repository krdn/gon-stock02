# Issue #11 — 필수 검증과 조건부 조사

2026-11-14 사용자가 필요한 작업의 판단과 분리를 위임했다. [Issue #11](https://github.com/krdn/gon-stock02/issues/11)은 백테스트 입력 계약의 완료 여부를 관리한다. 공개 조사를 계속 이어가는 실행 목록으로 쓰지 않는다.

[PR #36](https://github.com/krdn/gon-stock02/pull/36)은 2405/2433 개정이 비교한 일반 주식의 휴장·결제일 산정 조문을 바꾸지 않았다는 제한적 추론을 남겼다. 문서 연결을 더 찾는 작업보다 실제 수신·계좌 비용 검증을 우선한다. 날짜별 실제 결제와 계좌 적용은 이 결과로 확정되지 않았다.

#37·#38은 #11의 필수 하위 작업이다. #39는 관련 대기 작업이며 무조건적인 선행 조건으로 연결하지 않는다. #5는 주문 장부 구현이 완료된 기록으로 유지하고, 남은 장중 실증은 #38에서 추적한다.

## 조사 재개와 종료

- 담당 AI는 해당 이슈의 시작 조건부터 확인한다. 조건이 없으면 대기하며 다른 공개 조사로 바꿔 시간을 채우지 않는다.
- #39는 **입력에 필요함 + 판정에 영향이 있음 + 새 확인 수단이 있음**을 모두 충족한 항목만 재개한다. 실제로 사용할 자료의 필수 검증을 생략하는 뜻은 아니다.
- 시행일·예고/공포 연결은 변경 조항이 해당 입력에 영향을 준다는 근거가 있을 때만 조사한다. 새 식별자 하나만으로 재개하지 않는다.
- 한 번 재개할 때 질문 하나, 영향받는 입력, 새 확인 수단, 종료 조건을 이슈에 남긴다. 답을 얻거나 새 근거가 없으면 종료한다. 동일 조건의 실패 요청·검색과 자동 후속 세션 생성을 반복하지 않는다.
- 예를 들어 2026-08-28 배당락을 포함한 과거 구간을 실제 사용하려면 필요한 배당 근거를 #39에서 검증한다. 그 자료를 쓰지 않는 앞으로의 수신 실증은 해당 과거 항목 때문에 기다리지 않는다.

## 유지하는 판정과 재개 자료

#11의 원래 다섯 수용 기준은 유지한다. 첫 기준만 완료이며 나머지 네 기준은 미완료다. 기준 2·3은 #37, 기준 4는 #38, 기준 5는 #11에서 확인한다. 선택한 자료에 과거 항목이 필요하면 #39의 해당 검증도 충족해야 한다.

과거 분봉 모의 미지원, 기업행동 8건·결제일 15일 HOLD, 시행 경계 null, 원본·예측·기존 증거를 보존한다. 미검증 자료를 입력으로 승인하지 않는다. 자료 선택/제외 규칙은 전략 결과 확인 전에 고정하고 제외에 따른 표본·적용 한계를 남긴다. 미확인 비용을 0으로 채우거나 신호 구간을 보간하지 않는다.

이번 요청에서는 작업만 분리한다. 수신·주문·백테스트·새 세션·예약 실행은 시작하지 않는다. 주문 OFF·`backtest_ready=false`를 유지한다.

재개 시 AGENTS → WORKFLOW → STATE → 이 파일 → 선택한 이슈와 운영 문서만 읽는다. 데이터는 [수신 운영](../operations/minute-capture.md), 비용은 [주문 운영](../operations/paper-order-ledger.md)·[리뷰](../reviews/paper-order-ledger-2026-11-13.md)가 기준이다. 과거 조사는 선택한 항목의 기존 증거만 추가로 읽는다. 이전 작업 파일의 다음 행동은 이 분리표의 시작 조건을 충족할 때만 유효하다.
