# 과거 자료와 비용의 사용 조건

결론: 수집 파일의 구조 검사는 통과했지만 백테스트 사용은 보류한다. [Issue #9](https://github.com/krdn/gon-stock02/issues/9) · [수집 운영](../operations/historical-data.md) · [계산·출처·해시](../evidence/data-readiness-2026-11-13.json).

## 데이터 계약

2026-11-13 23:14 KST에 다시 받은 [공식 API 규격](https://apiportal.koreainvestment.com/files/download/apiCollection/API_COLLECTION)은 과거 분봉과 국내휴장일 조회의 모의환경을 미지원으로 표시한다. 원주가 일봉은 모의환경 지원이다. 현재 과거 분봉이 응답했다는 관측과 공식 지원 계약을 분리한다. 새 manifest는 주기별 `contract_mock_supported`를 기록한다.

4종목·5일의 정규장 분봉 거래량 합계는 일봉과 20건 모두 달랐다. 장후·개장 전 범위를 추가 조회한 80페이지를 합해도 20건 모두 일치하지 않았다. 세션·장외/대량매매·집계 정의 중 무엇이 원인인지는 확인하지 못했다. 일봉을 정규장 분봉의 합계로 바꾸거나 차이를 수집 손실로 단정하지 않는다.

인접한 1분 구간 7,575건에서 `저가×거래량 ≤ 누적 거래대금 증가분 ≤ 고가×거래량`이 성립했다. 이 결과는 현재 응답의 필드 의미가 서로 맞는다는 검사다. 다른 공급자나 거래소 원본과의 독립 대조는 아니다. 첫 봉·종가 단일가·누락 봉 경계는 이 검사에서 제외했다.

주성의 3개 누락 후보는 좁은 조회에서도 없었으며, 주변 누적 거래대금과 OHLC만으로 무거래를 확정하지 못했다. 그 시각을 사용하는 전략 구간은 보류한다. 기존 원본·정규화 파일은 수정하지 않았다. 새 계약 표시를 검증한 92페이지 재생에서도 정규화 8,593행은 기존 파일과 바이트 단위로 같았다. 재생은 새 네트워크 수집이 아니다.

## 공개 비용 기준

현재 [모의투자 공개 프로그램](https://vts3.koreainvestment.com/js/app_vts_hantoo_bundle.js)에서 확인한 표다. 계좌의 실제 차감 내역은 아직 없다.

| 항목 | 확인한 공개 값 | 미확인 |
|---|---|---|
| 주식 매매 수수료 | 편도 0.0142% | 주문/종목/일별 합산과 원 단위 반올림·절사 |
| 코스피 매도 세금 | 합계 0.20%: 거래세 0.05%+농특세 0.15% | 모의계좌 실제 차감 |
| 코스닥 매도 세금 | 거래세 0.20% | 모의계좌 실제 차감 |
| 스프레드·슬리피지 | 실측 없음 | 0으로 채우지 않음 |

세율은 [증권거래세법 시행령 제5조](https://www.law.go.kr/lsLinkCommonInfo.do?lspttninfSeq=64014&chrClsCd=010202)와 [증권사 세금 안내](https://securities.koreainvestment.com/main/customer/guide/_static/TF04ae010000.jsp)로 교차 확인했다. 실제 매매 수수료표는 계좌·매체에 따라 다르므로 모의투자 표와 혼합하지 않는다.

공개 값을 적용해 100만 원에 매수하고 같은 금액에 매도하면 수수료 142원씩과 매도 세금 2,000원, 합계 2,284원이다. 이는 반올림 전 산술 예시다. 스프레드·슬리피지·시장충격을 포함하지 않으며 실제 모의계좌 차감 검증이 아니다. 현재 값을 2025년 거래까지 소급하지 않는다.

위험 계산기의 비용 입력은 이번에 자동 연결하지 않았다. 장중 1주 왕복 체결 후 주문·체결·일별 비용을 대조하고, 적용일·반올림·원장 차감 시점을 고정해야 한다. 그 전에는 `backtest_ready=false`를 유지한다.
